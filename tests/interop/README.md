# Ente crypto interoperability evidence

The committed `ente_crypto_dart_981a9e0.json`, `ente_auth_backup_v1_dart_981a9e0.json`, and `ente_login_crypto_dart_981a9e0.json` fixtures were generated by Ente's `ente_crypto_dart` at revision `981a9e0f4a227023991af3332ef0e6ab6d14a1c2`, using Flutter 3.38.10 from Ente CI. The .NET tests prove that the implementation decrypts Dart secretstream entities, secretbox-wrapped authenticator keys, Argon2id-derived version-1 backups, the login subkey, and sealed session tokens.

The generator test in this directory can be copied into that Dart revision's `test/` directory. Run it with `flutter test`. Supplying `NET_VECTOR_PATH` makes Dart decrypt fresh .NET entity/key-wrap output; supplying `NET_BACKUP_PATH` makes Dart derive the backup key and decrypt a fresh .NET backup. Both directions were executed successfully while introducing the codecs; no production keys or account data are present in these fixtures.
